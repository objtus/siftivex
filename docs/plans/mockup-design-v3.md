# Mockup v3 デザイン方針

2026-10-11。mockup（素の HTML/JS）を実用ツールとして作り直すための方針メモ。

## ブリーフ（ユーザー回答）

- 用途: 探す ⇔ 見る を行き来する。実用性・機能主義、情報密度は高めでよい
- テーマ: ダーク / ライト切替
- グリッド: 並べ方を切替（行揃え / Masonry / 正方形 / 表）
- サムネに情報は載せない
- 閲覧: 案 B（探索 ⇔ 閲覧）を洗練
- 絞り込み: 左サイドバー常設
- キーボード: 移動系が使えれば十分
- Layout Lab は廃止。API 接続・索引状況は設定へ
- 対応: PC / タブレット / スマホ

## 主題

4 万枚規模の個人アーカイブ（pixiv 作品の複数ページ + iPhone 写真）を、タグと自然言語で絞り込み、
作品単位でめくって確認する作業台。画像が主役で、UI は「位置」「絞り込み状態」「タグの出どころ」を正確に示す計器。

## トークン

| 名前 | ダーク | ライト | 用途 |
|------|--------|--------|------|
| bg | `#1c1f23` | `#e9ebee` | グリッドの地 |
| surface | `#23272c` | `#f6f7f8` | バー・パネル |
| line | `#363c44` | `#d3d8de` | 区切り |
| text | `#e3e6ea` | `#1a1e23` | 本文 |
| accent | `#f0b429` | `#e0a100` | 選択中・含む・フォーカス（画像の上でも見える黄） |
| exclude | `#ef6b5b` | `#c8402f` | 除外 |

タグの出どころは色点で区別: d1 構造化 = 青、ファイル名 / pixiv = 緑、Tagger = 無彩色。

- 書体: BIZ UDPゴシック 1 ファミリー（UD 書体。小さいサイズでの判読性を優先）。数字は tabular。
- 文字サイズ: 11 / 12 / 13 / 15px。UI 本文 12px。
- 角丸: 画像 0（コンタクトシート）、操作部品 4px。影は使わない（オーバーレイのみ）。

## レイアウト

探索（PC）

```
┌ topbar ──────────────────────────────────────────────┐
│ Siftivex  [ 検索                          / ]   [設定] │
├ sidebar ──┬ toolbar ─────────────────────────────────┤
│ ルート     │ 200 / 40,320 件  履歴      並び  ▦▥▤☰  ─○─ │
│ 絞り込み中 ├──────────────────────────────────────────┤
│ 結果のタグ │ grid（無限スクロール）                      │
└───────────┴──────────────────────────────────────────┘
```

閲覧（PC）: 画像を最大化し、右に情報パネル（作品・ページ一覧・タグ・ファイル）。

```
┌ viewer bar: [一覧へ]  ‹ 4 / 200 ›                      ┐
├ image ────────────────────────────┬ info 360px ───────┤
│ ‹                               › │ 作品名 / 作者 / 日付 │
│                                   │ ページ 2/5 [ ]      │
│                                   │ ▢▢▢▢▢ ページ一覧     │
│                                   │ タグ（出どころ別）   │
└───────────────────────────────────┴───────────────────┘
```

## タブレット / スマホ

- 1100px 未満: サイドバーは左から出るドロワー（topbar の絞り込みボタン）
- 900px 未満: 閲覧は画像の下に情報パネルを積む。「情報」ボタンで隠すと画像が全面に
- タッチ: 画像を左右スワイプで前後へ。ブラウザの戻る / Android の戻るで一覧へ戻る

## 削除したもの

- Layout Lab（列数・ペイン幅などの調整）: グリッドサイズのスライダーに集約
- 案 A、複数選択バー、再タグボタン: 機能が未実装のため
- 類似画像（色味 / 時期 / モチーフ）: 実際には一覧の先頭 8 件を出すだけだったため
